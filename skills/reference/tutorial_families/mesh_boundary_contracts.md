# Tutorial Family: Mesh, Patch, Zone, and Interface Contracts

## Use

Structural reference when the decision is about mesh utility order, patch semantics, cellZone/faceZone creation, cyclic/cyclicAMI pairing, MRF regions, imported-mesh mapping or multi-region interfaces.

## Required match

Entity type, producer utility, consumer dictionary, exact transform/axis/origin relation, mesh dimensionality, region ownership and OpenFOAM-13 syntax.

## Reusable structure

Utility sequence, dictionary section layout, interface pairing concepts, inventory checks and visualization/`checkMesh` evidence may be reused.

## Never copy blindly

Patch/zone names, geometry selections, rotation axis/origin/speed, AMI transforms, porous/source coefficients, scale, mesh quality settings or region mapping.

## Evidence focus

Actual boundary/zone inventory, spatial location/membership, paired interface compatibility/overlap, topology/quality and every consuming dictionary reference.
