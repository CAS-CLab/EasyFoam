# Cumulative Evidence Claim Levels

Use the highest level for which all lower prerequisites pass.

1. **requirement_mapped** — explicit target preserved and decisive planning gaps resolved.
2. **case_contract_valid** — formal fields, dictionaries, models, boundaries, controls and hashes are consistent.
3. **mesh_credible** — required topology/patches/zones/quality and intended resolution evidence are acceptable.
4. **executed** — the selected formal attempt reached its declared terminal condition.
5. **numerically_credible** — convergence/timestep/boundedness/conservation evidence supports the intended numerical claim.
6. **physically_credible** — problem-specific physical principles/comparisons support the result.
7. **qoi_supported** — each required QoI has a valid method, criterion/status basis and evidence.

A higher stage cannot compensate for a failed lower prerequisite. Visual evidence is traceability/interpretation support and does not create a separate credibility level.
